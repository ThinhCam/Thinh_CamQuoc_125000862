# Portfolio cá nhân — Cam Quốc Thịnh

Website giới thiệu sinh viên Công nghệ thông tin, định hướng Front-end Developer.

## Cấu trúc
- `index.html`: Nội dung và cấu trúc semantic HTML5 chuẩn xác.
- `style.css`: Giao diện, CSS Variables, Flexbox/Grid, hiệu ứng thuần CSS và thiết kế responsive.
- `PROMPT_LOG.md`: Nhật ký prompt, các bước tinh chỉnh, giải quyết sự cố và tự đánh giá.

## Chạy thử
Mở file `index.html` trực tiếp bằng bất kỳ trình duyệt web nào hoặc sử dụng tính năng Live Server trong VS Code để xem trước giao diện.

## Triển khai GitHub Pages
1. Tạo repository theo mẫu giảng viên yêu cầu: `Ten_Ho_MSSV`.
2. Đưa các file vào thư mục gốc repository.
3. Commit và push lên branch `main`.
4. Vào Settings → Pages.
5. Chọn Source `Deploy from a branch`, Branch `main`, Folder `/ (root)`, rồi Save.
6. Chờ GitHub triển khai và mở URL được hiển thị ở phần Pages.

## Trước khi nộp
- Thay email mẫu `camquocthinh@example.com` bằng email thật nếu muốn công khai.
- Đính kèm đường link GitHub Pages vừa tạo vào phần **About** của Repository.
- Kiểm tra lại nội dung thông tin cá nhân, kỹ năng và mô tả dự án cho chính xác.
- Chỉnh sửa `PROMPT_LOG.md` phản ánh đúng quá trình thực hiện bài tập.
